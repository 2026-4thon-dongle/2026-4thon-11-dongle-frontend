## 설정

`.env.example`을 참고해 `VITE_API_BASE_URL`에 `/api/`를 제외한 서버 origin을 넣는다. 기본 서버는 `https://dongle-api.zanviq.dev`이고, 명시적인 빈 값은 동일 origin의 `/api/`로 요청한다. 환경변수 변경 후 Vite를 재시작한다.

11월 16일 `api/common.md`, `api/auth.md`, `changes/1116_be_hosting-deploy.md`, `requests/1116_be2fe_api-server-open.md`를 기준으로 기본 서버를 설정했다. `.env.local`은 로컬 설정으로 Git에 포함하지 않는다.

배포 서버 `GET /api/regions/`는 실제 HTTP 200, 시·도 17개를 반환했다. `Origin: http://localhost:5173`에 대한 `Access-Control-Allow-Origin: http://localhost:5173`도 확인했다. Vite는 해당 출처를 유지하도록 localhost:5173을 사용하고 포트 자동 변경을 막는다. 3000도 문서상 허용 출처다.

인증 코드는 실제 학교 메일함이 아니라 `https://dongle-mail.zanviq.dev`의 Mailpit에서 확인한다. 인증 요청·응답 계약은 동일하다. 실서버 가입·로그인·일기 변경·사진 업로드와 브라우저 E2E는 미검증이다.

실제 API가 기본이다. `VITE_API_MOCK=true`인 개발 환경에서만 기존 데모를 사용한다. 운영 빌드에서는 목 데이터를 활성화하지 않는다. `VITE_DEV_ACCESS_TOKEN`은 사용하지 않으며 인증 응답의 토큰을 저장한다.

## 연결 내용

- 01: 학교 메일 코드 발송·재발송·확인, 서버 만료·재발송 시간, 남은 인증 시도, 닉네임 중복 검사, 공식 지역 트리·ID, 약관과 가입, 로그인·프로필 복원, 첫 일기 완료 여부 분기.
- 02: 서버 글감과 현재 글감을 제외한 재추천, 첫 일기 multipart 작성, 서버 성공 후 첫 일기 완료 상태 반영.
- 03: 고향·전체 타지 피드, 서버 지역 필터, 페이지 목록, 새 일기 수·확인 기록, 안 읽은 알림 수, 일기 상세·배송 예상·서버 답장 권한, 신고 사유 코드 변환과 차단, 알림 목록·읽음과 종류별 경로 이동.
- 06: 내 일기 목록·다음 페이지·상세, 글감, 작성·수정·사진 유지/교체/제거·삭제·공개 범위. 사진은 JPEG·PNG·WEBP, 최대 5MB.
- 공통: Bearer 인증, 동시 401 단일 갱신, access·refresh 회전과 한 번 재시도, 임시 갱신 오류 시 토큰 유지, 세션 무효 시 공유 데이터 초기화·로그인 이동, 오류 code·message·errors·추가 필드 보존.

편지로 답장하기는 서버의 `can_reply`를 따르며 기존 04 경로로 이동한다. 편지 발송 자체와 05·07 화면은 이 작업의 검증 범위 밖이다. 보류 기능의 API를 새로 만들지 않았다. 푸시 제공자 등록·메일 발송은 프론트 조회·설정 연결만으로 완료되지 않는다.

- 06: `158:1842`의 엽서형 목록(항공우편 줄·우표·소인·줄노트·받은 편지 배지). 목록 수·편지 수는 서버 값을 사용한다.
- Jua·Gowun Dodum·Nanum Pen Script를 공식 Google Fonts 저장소에서 받아 WOFF2로 압축해 로컬에 포함했다. 외부 폰트 로딩 실패를 해결하며 원래 지정된 폰트 이름·용도는 같다. 각 폰트의 OFL 라이선스를 함께 저장했다.

시각·상호작용 검사는 로컬 Playwright 스크립트에서 API 응답을 가로채 수행했다(스크립트·캡처·변환 도구는 Git 제외 대상인 `.local/`에 보관). 실제 배포 DB에 메일·신고·차단·일기를 만들거나 삭제하지 않는다. 28개 화면 상태를 320·360·430·768px에서 확인하고, 폰트 로딩·이미지 로딩/비율·가로 넘침·브라우저 실행 오류·인증 오류 복구·글감 삽입을 검사한다. API 계약 검사는 글감 삽입을 포함해 24개 시나리오다. 04·05·07 화면 코드는 변경하지 않았다.
